# SlotCat.ai

SlotCat.ai is an interactive product prototype for AI-assisted meeting scheduling across time zones.

The demo lets users describe a meeting request in natural language, then shows suggested meeting windows, timezone tradeoffs, fairness rotation, and an interactive time exploration view.

## Project Scope

- Product positioning and MVP definition
- Interactive landing page and scheduling prototype
- Timezone-aware recommendation simulation
- Fairness-focused meeting window presentation
- Public demo prepared for deployment and user feedback

## Current Status

This is a front-end prototype built with HTML, CSS, and JavaScript. It does not currently connect to live AI, calendar, authentication, payment, or database services.
